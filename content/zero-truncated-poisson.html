从模型开始ln(1 + T) 的角色给定总和UMVUE配套练习

本文根据考后回忆重建可能涉及的知识链。原题完整题干、参数化与选项尚未确定，因此不能只凭“ln(1 + T)”确认原题考的是哪一种结论。

1. 先确认：零值被截掉了

设 X₁，…，Xₙ 独立同分布，服从参数 λ > 0 的零截断泊松分布。普通泊松变量以“严格大于零”为条件后，得到

Pλ(X = k) = λk / [k! (eλ − 1)]，　k = 1, 2, …

与普通泊松相比，分母变了，支持集也变了。这里每一个观测值都至少为 1，所以总和 T = ΣXᵢ 必须满足 T ≥ n。零截断泊松的均值为 λ / (1 − e−λ)，并不是 λ。

2. ln(1 + T) 可能考查的角色：一一变换

样本联合概率为

L(λ; x₁,…,xₙ) = λT / [(eλ − 1)n ∏xᵢ!]，　xᵢ ≥ 1。

样本与参数发生联系的部分只通过 T，因此由因子分解定理，T 是 λ 的充分统计量。令 η = ln λ，其自然参数空间为整个实数轴；这是支持集不依赖参数、自然参数空间含开集的一参数满指数族，因此 T 也是完备统计量。

如果题目又定义 V = ln(1 + T)，由于 T = eV − 1，二者可以相互恢复。给出 V 与给出 T 包含同样的样本信息。因此：

T 充分且完备　⇒　ln(1 + T) 也充分且完备。

充分性保留，是因为一一变换没有丢失信息。完备性保留，是因为任何满足 E[g(V)] = 0 的函数，都能写成 h(T) = g(ln(1 + T))，再应用 T 的完备性。

不能从这里直接跳到“这是 λ 的 UMVUE”充分、完备描述的是统计量所含的信息；无偏描述的是期望等于哪个待估函数。要说 V 是 λ 的无偏估计，仍然必须证明 E[V] = λ。通常这并不成立。

一个快速检验：因为 T ≥ n，必有 ln(1 + T) ≥ ln(1 + n)。因此，只要 0 < λ < ln(1 + n)，就有 E[ln(1 + T)] ≥ ln(1 + n) > λ。这已经足以证明它不能在所有 λ > 0 上无偏估计 λ。若原题估计的是另一个参数函数，则必须先确认那个函数是什么。

3. 固定 T = N 后，样本的联合分布是什么？

这里 n 是样本量，N 是已经固定的总和，k₁，…，kₙ 是各个观测取值。条件事件有可能发生，必须有 N ≥ n；合法取值必须满足每个 kᵢ ≥ 1 且 Σkᵢ = N。

先用三个观测、总和为 5 算一遍

“每个 Xᵢ 对应一个 k”可能是两种问题：指定全部坐标，例如 X₁ = 1、X₂ = 1、X₃ = 3，是联合事件；只问 X₁ = 1，是边缘事件，要将其余坐标的全部合法分配加起来。

当 n = 3、T = 5 时，三个正整数相加为 5 只有下面六种有序向量。每个向量的相对权重为 1 / (k₁! k₂! k₃!)，总权重为 3 × 1/6 + 3 × 1/4 = 5/4。

(X₁, X₂, X₃)相对权重给定 T = 5 的概率
(1, 1, 3)1/62/15
(1, 3, 1)1/62/15
(3, 1, 1)1/62/15
(1, 2, 2)1/41/5
(2, 1, 2)1/41/5
(2, 2, 1)1/41/5

只问 X₁ = k 时，把第一坐标相同的行加起来：

P(X₁ = 1 | T = 5) = 2/15 + 2/15 + 1/5 = 7/15；
P(X₁ = 2 | T = 5) = 1/5 + 1/5 = 2/5；
P(X₁ = 3 | T = 5) = 2/15。

其余 k 的概率为 0；这三项相加为 1，条件均值为 5/3。注意“指定向量 (1,1,3)”的概率是 2/15，而“不管顺序、其中两个为 1，一个为 3”的概率是 3 × 2/15 = 2/5。固定总和后，三个变量也不再独立。

再把例子写成一般公式

把联合概率除以 P(T = N)，其中的 λN 与 (eλ − 1)−n 消去，得到一个与 λ 无关的条件分布。记 S(N,n) 为第二类 Stirling 数，即把 N 个有区别的对象分成 n 个非空无标号组的方法数，则

P(X₁ = k₁,…,Xₙ = kₙ | T = N)
= N! / [n! S(N,n) ∏kᵢ!]，　kᵢ ≥ 1，Σkᵢ = N。

不满足上述支持集的取值，条件概率为 0。归一化来自恒等式：

Σkᵢ≥1, Σkᵢ=N N! / ∏kᵢ! = n! S(N,n)。

组合解释很直接：把 N 个有区别的对象投进 n 个有标号的盒子，而且每盒必须非空。固定各盒数量 k₁，…，kₙ 时，有 N! / ∏kᵢ! 种投放方式；所有满射共有 n! S(N,n) 种。

样本模型给定总和后的分布
普通独立同参数泊松Multinomial(N; 1/n,…,1/n)，允许某格为 0
零截断独立同参数泊松上面的多项分布，再条件于所有格子都大于 0

因此，零截断情形不是未经条件化的普通多项分布，也不是在所有正整数分拆上等概率分配。不同向量的概率与 1 / ∏kᵢ! 成正比。

只问其中一个 Xᵢ 呢？

利用对称性，每个 Xᵢ 的条件边缘分布都相同。当 n ≥ 2 时：

P(X₁ = k | T = N)
= C(N,k) S(N−k,n−1) / [n S(N,n)]，
k = 1,…,N−n+1。

如果题目只要条件均值，则不必计算这些 Stirling 数。因为条件分布仍然对各个样本位置对称，且 ΣXᵢ = N，所以 E(Xᵢ | T = N) = N/n。

n = 2 时，式子会简单很多

由于 2! S(N,2) = 2N − 2，

P(X₁ = k | T = N) = C(N,k) / (2N − 2)，
k = 1,…,N−1。

例如固定 T = 4，那么 (X₁,X₂) 只可能为 (1,3)、(2,2)、(3,1)，相应概率分别是 2/7、3/7、2/7。两端的 (0,4)、(4,0) 已被截掉；三个剩余向量也不是各占 1/3。

4. 为什么条件分布正好能用来求 UMVUE？

设要估计 qλ(k) = Pλ(X = k)，其中 k ≥ 1 是固定整数。最容易找到的无偏估计是指示变量 I{X₁ = k}，因为其期望正好等于 qλ(k)。再对完备充分统计量 T 取条件期望：

δk(T) = E[I{X₁ = k} | T]
= C(T,k) S(T−k,n−1) / [n S(T,n)]。

在 1 ≤ k ≤ T−n+1 时使用该式，否则取 0。这就是 n ≥ 2 时 qλ(k) 的 UMVUE。n = 1 时，T = X₁，本身的指示变量已经是完备充分统计量的函数。

如果原题写成普通泊松概率 pλ(k) 除以 1 − e−λ，那么它正好等于 qλ(k)。但仍需确认样本自身是“普通泊松”还是“零截断泊松”；二者的条件分布和无偏估计构造不能混用。

待估函数若是 λ，又该怎么办？

对于一个零截断泊松观测，U = X₁ I{X₁ ≥ 2} 是 λ 的无偏估计。直接求和可得：

E[U] = [Σj≥2 j λj/j!] / (eλ−1)
= λ(eλ−1)/(eλ−1) = λ。

对 T 条件化，可把 U 写成 X₁ − I{X₁ = 1}。由 E(X₁|T) = T/n 得到 λ 的 UMVUE：

δ(T) = T/n − T S(T−1,n−1)/[n S(T,n)]
= T S(T−1,n) / S(T,n)。

最后一步用了第二类 Stirling 数递推 S(T,n) = nS(T−1,n) + S(T−1,n−1)。当 n = 2 时，

δ(T) = T/2 − T/(2T−2)。

例如 T = 4 时，这个估计值为 12/7。它既不是 T/n，也不是 ln(1 + T)。三者扮演的角色不同，需要分别验证。

5. 再多想一步：最大似然与无偏并非一回事

对数似然求导得到得分方程：

T/n = λ / (1 − e−λ)。

若 T > n，左侧大于 1，该方程有唯一正根，通常需要数值求解；一般不能把它直接改写为 ln(1 + T)。若 T = n，则所有 Xᵢ 都是 1，似然的上确界在 λ ↓ 0 时取得极限；在参数空间 λ > 0 内没有取得最大值的点。

比如 n = 3、T = 5 时，λ 的 MLE 约为 1.1263；λ 的 UMVUE 为 5S(4,3)/S(5,3) = 6/5，而 ln(1 + T) = ln 6。这三个数不一样，并不矛盾。

Fisher 信息：区分变换统计量与变换参数

将零截断的归一化项也一同求导，单个观测与 n 个独立观测的 Fisher 信息分别为：

I₁(λ) = [1 − (1 + λ)e−λ] / [λ(1 − e−λ)²]，
Iₙ(λ) = n I₁(λ)。

保留 V = ln(1 + T) 时，T 可以完整恢复，关于同一个参数 λ 的 Fisher 信息不变。但若把参数本身换成 η = ln λ，信息要按参数变换规律改写：

Iₙ(η) = (dλ/dη)² Iₙ(λ) = λ² Iₙ(λ)。
考场检查顺序先写支持集 → 再分清普通泊松与零截断泊松 → 看问题究竟要充分性、条件分布、无偏估计还是最大似然 → 最后代入数值。看到 ln(1 + T) 时，先找它在题干中“被定义为什么”。
