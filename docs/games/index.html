从雪松溪牧场出发，骑马赶牛、练习套索，参加牛仔大赛。沿着一封录取信，走进林野与家人的故事。

训练与比赛故事旅程电脑 / 手机
开始游戏 ↗手机触控模式

游戏进度保存在当前浏览器。与刷题记录独立，不影响学习进度。

电脑操作

WASD 移动，鼠标瞄准，按住左键蓄力，松开投绳。Esc 暂停后可返回题库。

手机操作

横屏游玩，左侧摇杆移动，右侧按钮投绳。竖屏可以选牛、换装和阅读故事。

保存与声音

点击开始后才播放声音，可在游戏中关闭。清除浏览器数据会清除这台设备的游戏存档。

游戏里的奖金仅为剧情数值。首次进入游戏需加载配乐资源。
