已知 T = N，怎样求一般条件分布与 UMVUE？

以 pλ(k)/(1 − e⁻λ) 为待估函数，保留 N 为字母，写出条件分布、无偏估计与最小方差依据。

关于 N 的一般答案Stirling 数为何是 UMVUE条件分布ln(1 + T)配套练习

本文按“样本独立同分布于零截断泊松”这一明确条件重建推导。原题尚未完整确认；如果原题样本来自普通泊松，下面的条件分布不能直接套用。

1. 先给出：观察到 T = N 时的一般答案

n 是样本量，T = ΣXᵢ 是随机总和，N 是已经观测到的总和值，k ≥ 1 是事先固定的整数。不能把 n 与 N 混为一谈，也不是把 k 当成待估参数。下面始终假设 n ≥ 2，λ > 0，X₁，…，Xₙ 独立同分布于零截断泊松。

若 pλ(k) = e−λλk/k! 是普通泊松的单点概率，题目要估计的函数为

qλ(k) = pλ(k) / (1 − e−λ)
= λk / [k! (eλ − 1)]，　k = 1, 2, …

它正好是本模型的 Pλ(X₁ = k)。其 UMVUE 作为一个统计量，写成

δk(T) = C(T,k) S(T−k,n−1) / [n S(T,n)]，
当 1 ≤ k ≤ T−n+1；其他情形取 0。

如果题目已经给定观测到 T = N，把随机变量 T 换成这个观测值 N，最终的估计值就是：

δk(N) = C(N,k) S(N−k,n−1) / [n S(N,n)]，
N ≥ n，　1 ≤ k ≤ N−n+1；
对其他固定整数 k，δk(N) = 0。

这里 C(N,k) 是组合数，S(N,n) 是第二类 Stirling 数，定义与计算方法见下一节。N < n 在这个模型下不可能观测到，因为每个 Xᵢ 至少为 1。

如果样本量恰好是 n = 2

由 2!S(N,2) = 2N−2，一般答案立刻简化为：

δk(N) = C(N,k)/(2N−2)，
N ≥ 2，　k = 1,…,N−1；支持外取 0。

N 仍然是题目给定的总和，不必代入某个特定数值。这也是两个零截断泊松样本给定总和后，任意一个 Xᵢ 的条件分布。

统计量和估计值要区分δk(T) 是抽样前的随机估计量；δk(N) 是观测总和为 N 后算出的具体估计值。“无偏”说的是 Eλ[δk(T)] = qλ(k)，不是说每一个固定 N 下，δk(N) 都等于未知的 qλ(k)。

2. S(N,n) 是什么，考场上怎样写？

S(N,n) 表示把 N 个有区别的对象分成 n 个非空、无标号组的方法数。把组再贴上 n 个盒子的标签，方法数就是 n! S(N,n)。可用以下递推计算：

S(N,n) = nS(N−1,n) + S(N−1,n−1)。
S(0,0) = 1；
S(N,0) = 0（N > 0）；
S(N,n) = 0（0 ≤ N < n）；
S(N,N) = S(N,1) = 1（N ≥ 1）。
不使用 Stirling 数记号：展开有限和形式

如果不想引入 Stirling 数记号，也可以用有限求和写出同一个答案。令

Am(r) = Σj=0,…,m (−1)m−jC(m,j)jr = m!S(r,m)。

在上面给出的合法支持范围内，r 为正整数，不涉及 00 的处理。于是可等价写成

δk(N) = C(N,k) An−1(N−k) / An(N)。

这一形式本质上用容斥原理数“每个盒子都非空”的放法。若题目直接给了 S 的数值或定义，使用前一个式子通常更简洁。

3. 推导主线：从无偏估计到 UMVUE

第一步：先找到一个无偏估计

固定 k ≥ 1，取 Uk = I{X₁ = k}。由指示变量的期望公式，

Eλ[Uk] = Pλ(X₁ = k) = qλ(k)。

因此 Uk 对目标函数无偏。这一步只能得到“无偏”，不能直接宣布它是 UMVUE。

第二步：对总和 T 取条件期望

Rao–Blackwell 化得到

δk(T) = E[Uk | T] = P(X₁ = k | T)。

给定 T = N 时，利用 X₁ 与其余 n−1 个观测独立，先求条件概率：

P(X₁ = k | T = N)
= P(X₁ = k) P(X₂ + ⋯ + Xₙ = N−k) / P(T = N)
= C(N,k) S(N−k,n−1) / [n S(N,n)]。

支持集为 1 ≤ k ≤ N−n+1：X₁ 至少为 1，其余 n−1 项也必须各自至少为 1。分子、分母中的 λ 次幂与零截断归一化因子全部抵消，所以这个条件分布不含 λ。

第三步：证明无偏性仍然保留

Eλ[δk(T)] = Eλ{E[Uk | T]}
= Eλ[Uk] = qλ(k)。

这一步用的是全期望公式。δk(T) 的取值在 0 与 1 之间，所需的期望与方差均存在。

第四步：补上完备充分性，才能判定 UMVUE

样本联合似然为

L(λ; x₁,…,xₙ) = λT(eλ−1)−n ∏(1/xᵢ!)，　xᵢ ≥ 1。

因子分解定理表明 T 充分。令自然参数 η = ln λ，则 η 可以取整个实数轴；这是支持集不依赖参数、自然参数空间含开集的一参数满指数族，所以 T 也完备。δk(T) 是完备充分统计量 T 的函数，并且对 qλ(k) 无偏，故由 Lehmann–Scheffé 定理，它是该目标函数的 UMVUE。

考场可以压缩成这条链I{X₁ = k} 无偏 → 对 T 条件化，得到关于 N 的条件概率公式 → 因子分解证明 T 充分，满指数族证明 T 完备 → Lehmann–Scheffé 得到 UMVUE。单独证明“无偏”，缺少最后的最小方差依据。

4. 所需的总和分布与联合条件分布

总和 T 的分布用于上面的分母。对整数 N ≥ n，

Pλ(T = N) = n!S(N,n) λN / [N!(eλ−1)n]。

它一般既不是 Pois(nλ)，也不是仅在 0 处截断的 Pois(nλ)。因为这里要求的是每一个原始观测都大于 0。

如果题目同时指定每一个坐标为 kᵢ，即要求 X₁ = k₁，…，Xₙ = kₙ，那么对 kᵢ ≥ 1 且 Σkᵢ = N，联合条件分布为

P(X₁ = k₁,…,Xₙ = kₙ | T = N)
= N! / [n!S(N,n) ∏kᵢ!]。

不满足这些条件的向量概率为 0。公式的归一化恒等式为

Σkᵢ≥1, Σkᵢ=N N! / ∏kᵢ! = n!S(N,n)。

只问 Xᵢ = k 时，要对其余坐标的合法分配求和，就回到前面的一维条件分布。条件分布仍然对样本位置对称，所以每个 Xᵢ 的条件边缘公式相同，且 E(Xᵢ | T = N) = N/n。

样本模型给定总和后的联合分布
普通独立同参数泊松Multinomial(N; 1/n,…,1/n)，允许坐标为 0
零截断独立同参数泊松上述多项分布再条件于所有坐标都大于 0

所以不能直接套未经条件化的多项分布，也不能把所有正整数分配看成等概率。不同向量的权重与 1/∏kᵢ! 成正比。

若 n = 1，则 T = X₁，需单独写 δk(T) = I{T = k}，不套用前面 n ≥ 2 的边缘推导。

辅助核对：展开 n = 3、N = 5 的六种分配

这只是用小数值检查一般公式，不是答案的适用限制。此时 S(5,3) = 25；六种有序向量如下。

(X₁, X₂, X₃)相对权重给定 T = 5 的概率
(1, 1, 3)1/62/15
(1, 3, 1)1/62/15
(3, 1, 1)1/62/15
(1, 2, 2)1/41/5
(2, 1, 2)1/41/5
(2, 2, 1)1/41/5

把第一坐标相同的行相加，P(X₁ = 1 | T = 5) = 7/15，P(X₁ = 2 | T = 5) = 2/5，P(X₁ = 3 | T = 5) = 2/15。相应地，对固定 k = 2，qλ(2) 的 UMVUE 在本次观测下取值为 2/5。

另一个目标：如果题目估计的是 λ 本身

此时不能沿用 qλ(k) 的估计式。可先构造 U = X₁I{X₁ ≥ 2}，直接求和得 E[U] = λ；再对 T 条件化。观察到 T = N 时，λ 的 UMVUE 为

δλ(N) = N/n − N S(N−1,n−1)/[nS(N,n)]
= N S(N−1,n)/S(N,n)。

这个式子估计 λ；主线的 δk(N) 估计固定 k 对应的单点概率 qλ(k)。必须先读清待估函数，再决定用哪个无偏估计作起点。

5. ln(1 + T)：放回“统计量变换”的位置

若原题还定义 V = ln(1 + T)，由于 T = eV−1，二者能够相互恢复，因此 V 也完备充分。知道 V=v 后，可以先算 N=ev−1，再代入上述 δk(N)；无须另构造一套估计方法。

但 V 自身不自动成为 λ 或 qλ(k) 的无偏估计。比如 T ≥ n 导致 V ≥ ln(n+1)，只要 0 < λ < ln(n+1)，就有 E[V] > λ。因此充分、完备和无偏是需要分别判断的性质。

6. 延伸：MLE 与 Fisher 信息

对数似然求导，λ 的 MLE 方程为

N/n = λ/(1−e−λ)。

N > n 时有唯一正根，通常需要数值求解；N = n 时，λ > 0 的参数空间内没有取得最大值的点，似然仅在 λ ↓ 0 时趋向上确界。这与 UMVUE 是不同的估计方法。

单个观测与 n 个独立观测关于 λ 的 Fisher 信息分别为

I₁(λ) = [1−(1+λ)e−λ] / [λ(1−e−λ)²]，
Iₙ(λ) = nI₁(λ)。

保留 V = ln(1 + T)，不会减少关于同一个参数 λ 的 Fisher 信息，因为 T 可以恢复。若变换的是参数本身 η = ln λ，则按参数变换规律有 Iₙ(η) = λ²Iₙ(λ)。统计量变换与参数变换是两件事。
