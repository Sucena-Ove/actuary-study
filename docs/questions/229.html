正态样本方差的方差

正态样本的无偏样本方差为S²，样本量n≥2。Var(S²)为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：B
  1. (n−1)S²/σ²~χ²(n−1)，卡方方差为2(n−1)，按尺度变换得2σ⁴/(n−1)。
易错提醒先明确分布参数、独立性和统计量的定义，再进行计算。
