平方变换

X~U(−2,2)，Y=X²。当0<y<4时，Y的分布函数为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：D
  1. P(Y≤y)=P(−√y≤X≤√y)，区间长度为2√y，除以总长度4。
