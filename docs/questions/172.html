#172概率基本性质中等

条件抽样

8个球中3红5白，不放回取2个。已知至少有1红，恰有2红的概率为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：A
  1. 至少1红有C(8,2)−C(5,2)=18种，2红有C(3,2)=3种，条件概率3/18。
易错提醒先明确分布参数、独立性和统计量的定义，再进行计算。
