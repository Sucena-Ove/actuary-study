#438期望与预测中等

Beta-Bernoulli后验预测

先验θ服从Beta(1,1)。给定θ，各次试验条件独立为Bernoulli(θ)。观察4次成功、2次失败后，未来两次都成功的后验预测概率为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：B
  1. 后验为Beta(5,3)。未来两次给定θ时均成功的概率为θ²。
  2. 预测概率为后验二阶矩 。
易错提醒积分消去共同θ后，未来结果不再相互独立；不能直接平方后验均值5/8。
