#175概率基本性质基础

随机排列

5个不同对象等可能排成一列，指定的两个对象相邻的概率为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：D
  1. 将指定两对象视为一块，有4!×2种排列，总数5!，比为2/5。
易错提醒先明确分布参数、独立性和统计量的定义，再进行计算。
