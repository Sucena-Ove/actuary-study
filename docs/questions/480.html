#480抽样分布提高

随机子样本的最大值

有10个独立同分布的连续观测，独立于数值均匀选4个指标，取其观测最大值M。再独立、均匀地从全部10个指标中选I（可能在前4个里）。 是？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：D
  1. I落在已选4个指标中时不可能严格超过M；落在其余6个中的概率为6/10。
  2. 给定选中了外部指标，其观测与4个子样本构成5个独立同分布连续变量，超过最大值概率1/5。
  3. 相乘为 。
易错提醒从全体选与只从剩余未选指标选，答案不同。
