#464概率基本性质中等

好球改坏：已知首次抽样

袋中5好3坏，首次不放回抽2个，已知恰好一好一坏。把抽到的好球改为坏球，然后将这2个球全部放回。再不放回抽2个，至少有一个好球的概率为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：D
  1. 首次抽到的1个好球改坏后，袋中变为4好4坏，总数仍是8。
  2. 第二次至少一好概率 。
易错提醒放回的是球，颜色已改变；总数不变，但好球数减少。
