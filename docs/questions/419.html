#419随机变量与分布中等

Q-Q图：重尾偏离

正态Q-Q图横轴为标准正态分位数、纵轴为样本分位数。相对穿过中部的参考直线，左端明显偏低、右端明显偏高，最典型的解释为？
  1. A所有观测相互独立
  2. B总体均值必为0
  3. C样本分布两侧尾部较正态更重
  4. D样本分布两侧尾部较正态更轻
我已思考，展开答案与解析
正确答案：C
  1. 左端偏低意味着极小值更负，右端偏高意味着极大值更大。
  2. 在中心位置和尺度可比时，这支持比正态更重的双侧尾部。
易错提醒判断尾部方向要以题目约定的横纵轴为准。
