#353概率基本性质提高

连续成功与连续失败的竞争

每次独立试验成功概率为 。连续出现两次成功或连续出现两次失败时立即停止。最终以两次成功结束的概率为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：A
  1. 令 a、b 分别表示上次是成功、失败时最终以两次成功结束的概率。则 、，解得 。
  2. 第一次试验后全概率为 。
易错提醒只算首两次都成功会漏掉更晚停止的路径。
