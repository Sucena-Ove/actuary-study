正态混合方差

X以概率p来自N(0,1)，以概率1−p来自N(1,1)。Var(X)为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：B
  1. 全方差公式：类内方差的期望为1；类别条件均值为0、1，类间方差为p(1−p)。
易错提醒先明确分布参数、独立性和统计量的定义，再进行计算。
