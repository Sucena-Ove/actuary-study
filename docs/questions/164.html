#164随机向量中等

正态和的对称性

(X,Y)联合正态，边际为N(4,1)、N(6,99)。无论相关系数如何，P(X+Y≤10)为？
  1. A
  2. B
  3. C
  4. D无法确定
我已思考，展开答案与解析
正确答案：A
  1. 和是均值10的正态变量；其方差至少为(√99−1)²>0，因此在均值左侧的概率恒为1/2。
易错提醒先明确分布参数、独立性和统计量的定义，再进行计算。
