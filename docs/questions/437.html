Bayes二元决策的阈值

根据数据，事件H的后验概率为0.3。行动A表示接受H，H不成立却接受的损失为2；行动B表示拒绝H，H成立却拒绝的损失为5；其余损失为0。最优行动及后验风险为？
  1. A行动A，风险1.4
  2. B行动B，风险1.5
  3. C行动A，风险0.6
  4. D行动B，风险3.5
我已思考，展开答案与解析
正确答案：A
  1. 行动A风险 。
  2. 行动B风险 。
  3. 取较小风险，选择A。一般阈值为 时选A。
易错提醒误判损失不对称时，后验概率不必超过1/2才选择接受。
