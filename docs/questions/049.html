#049线性模型与回归中等

完全多重共线性

在线性模型 中，设计矩阵的第三个解释变量列在所有观测上都严格等于前两个解释变量列之和。下列说法正确的是哪项？
  1. A 奇异，普通最小二乘系数向量不能唯一确定
  2. B普通最小二乘系数一定仍然唯一
  3. C所有响应变量的观测值必为零
  4. D去掉任意一行就必能消除共线性
我已思考，展开答案与解析
正确答案：A
  1. 存在非零系数向量使设计矩阵列的线性组合为零，因此 X 不满列秩， 不可逆。
  2. 最小二乘系数有多个解；虽然系数不能唯一识别，拟合值仍可唯一确定。
易错提醒系数不唯一不等于拟合值不唯一；应调整重复的解释变量。
