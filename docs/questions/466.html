#466概率基本性质提高

一般标记抽样的后续分布

袋中m个好球、n个坏球。先不放回抽k个，已知其中h个好球；将这些好球改坏并把抽出的k个球全部放回。随后不放回抽s个，其中恰有j个好球的概率为（组合数越界视为0）？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：B
  1. 标记后好球数m−h，坏球数n+h，总数m+n。
  2. 从剩余颜色构成中作超几何抽样，选j个好与s−j个坏即可。
  3. 若问至少r个好，对j从r到可行上界求和。
易错提醒“改为坏球并放回”与“移除好球”是两个模型。
