互斥类别指示量

某次分类的 A、B、C 类概率为 0.8、0.1、0.1。令 I、J 分别为 A、B 类的指示量。相关系数为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：A
  1. ，协方差−0.08；方差为0.16、0.09，故相关系数为−0.08/0.12=−2/3。
易错提醒先明确分布参数、独立性和统计量的定义，再进行计算。
