#477抽样分布中等

新观测超过第k次序统计量

独立同分布且连续。按从小到大排列X样本， 为第三小。 是？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：A
  1. 将Y加入后，Y在9个观测中的秩均匀分布于1到9。
  2. 若Y的秩为1、2、3，则不超过原X样本的第三小；秩为4到9则超过。
  3. 因此概率6/9=2/3。
易错提醒固定原样本成员超过X_(3)的概率是5/8，与新观测情形不同。
