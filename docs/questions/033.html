#033估计理论基础

频率学派置信区间解释

对一个固定但未知的总体均值，按覆盖率恰为 95% 的程序反复独立抽样并构造区间。以下哪项是频率学派下正确的解释？
  1. A观察到的每个区间都必定包含总体均值
  2. B约 95% 的总体观测值落在每个区间内
  3. C区间中心就是总体均值
  4. D重复抽样所构造的区间中，长期约 95% 包含总体均值
我已思考，展开答案与解析
正确答案：D
  1. 随机的是样本及据此构造的区间，参数是固定的。
  2. 95% 描述该构造程序在重复抽样中的覆盖率，而不是总体观测值落入区间的比例。
易错提醒参数区间与个体观测值的预测区间不同。
