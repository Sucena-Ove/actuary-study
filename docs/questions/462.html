#462随机变量与分布提高

随机化概率积分变换

X以各1/2概率取0和1。V独立于X且服从U(0,1)，F为X的分布函数。令 。Y服从？
  1. A恒等于X
  2. B
  3. C
  4. D以各1/2概率取1/2和1
我已思考，展开答案与解析
正确答案：B
  1. X=0时，Y=V/2，在(0,1/2)内均匀。
  2. X=1时，Y=1/2+V/2，在(1/2,1)内均匀。
  3. 两个分支各占1/2，所以总密度在(0,1)上为1。
易错提醒额外的独立均匀变量把点质量摊开；不能漏掉左极限。
