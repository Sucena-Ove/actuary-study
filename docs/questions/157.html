#157期望与预测中等

配对和的离差平方和

2n个独立N(μ,σ²)变量， 是全部均值。令 。EY为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：B
  1. 令Aᵢ=Xᵢ+Xₙ₊ᵢ，则n个Aᵢ独立、方差2σ²，且它们的均值为2。离均差平方和期望为(n−1)倍总体方差。
易错提醒先明确分布参数、独立性和统计量的定义，再进行计算。
