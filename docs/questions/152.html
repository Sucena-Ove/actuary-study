#152随机向量提高

线性相关组合

Var(X)=Var(Z)=v>0，Var(Y)=4v，。X与Y+Z的相关系数为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：A
  1. 完全负相关给出中心化Y=−2X，故Cov(Y,Z)=−v。Var(Y+Z)=3v，Cov(X,Y+Z)=−3v/2。除以标准差积得−√3/2。
易错提醒先明确分布参数、独立性和统计量的定义，再进行计算。
