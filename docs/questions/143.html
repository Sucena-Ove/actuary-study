联合密度与相关系数

联合密度为，0<y<x<∞。X、Y的相关系数为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：D
  1. X为Gamma(2,1)，给定X时Y~U(0,X)。EX=2，VarX=2，EY=1，EY²=EX²/3=2，EXY=EX²/2=3。协方差1、VarY=1，故相关系数1/√2。
易错提醒先明确分布参数、独立性和统计量的定义，再进行计算。
