#322估计理论中等

直方图分布的均值

把 四组的频率 均匀摊在各组内，得到估计分布。该分布的均值是？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：B
  1. 四组均匀分布的均值为组中点 。
  2. 对组中点按概率质量 加权，即得所求均值表达式。
易错提醒求混合分布期望使用各组概率质量，不用密度高度作权重。
