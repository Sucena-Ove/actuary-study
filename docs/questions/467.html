#467概率基本性质提高

改变颜色并重复到同色

袋中2好2坏。每轮不放回抽2球，先看抽出时的颜色：若同色则停止，若异色则继续；每轮都把抽到的好球改坏，并将2球全放回（停止轮也如此）。停止后再抽2球，至少一好概率为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：C
  1. 令A(g)为袋中g个好球时按规则进行后的目标概率；总数恒为4。A(0)=0。
  2. g=1时，有1/2概率先抽到两坏并停止，之后至少一好的概率1/2；另1/2转到g=0，故A(1)=1/4。
  3. g=2时，抽两坏、两好、异色概率分别为1/6、1/6、4/6。
  4. 。
易错提醒必须说明在改变颜色之前判断是否停止，否则题目机制会完全不同。
