零截断泊松：边界MLE

有n个独立零截断泊松观测，参数空间为λ>0，观测全为1。关于λ的极大似然估计，哪项正确？
  1. AMLE等于1
  2. BMLE等于n
  3. CMLE等于0，且0属于题设参数空间
  4. D在λ>0内没有极大值，似然上确界在λ趋近0时达到极限
我已思考，展开答案与解析
正确答案：D
  1. 似然正比于 。
  2. λ>0时每个因子小于1，并随λ趋于0而趋于1；其导数为负。
  3. 0被参数空间排除，故只有边界上确界，没有内部MLE。
易错提醒“最优极限点”不一定属于参数空间；不能不加说明地写MLE=0。
