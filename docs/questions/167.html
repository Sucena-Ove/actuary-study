相邻差的方差估计

独立同分布样本方差为σ²。使 无偏估计σ²的c为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：D
  1. 每个平方差的期望为2σ²，求和期望为2(n−1)σ²。相邻差之间相关，不影响此期望计算。
易错提醒先明确分布参数、独立性和统计量的定义，再进行计算。
