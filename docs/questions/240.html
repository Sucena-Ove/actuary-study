指数速率无偏修正

样本来自Exp(λ)，n>1，T=ΣXᵢ。λ的无偏估计为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：A
  1. T~Gamma(n,λ)，E(1/T)=λ/(n−1)，故乘n−1无偏。最大似然估计n/T则上偏。
