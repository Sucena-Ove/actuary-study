#129期望与预测中等

最大次序统计量的均值

两人独立出价，均服从 U(1,2)。成交价取较大出价，期望为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：B
  1. 减去1后为两个U(0,1)变量，最大值均值为2/3。加回1得5/3。
