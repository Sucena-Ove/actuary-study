#348概率极限理论提高

Gamma 积分与中心极限定理

下列极限等于多少：？
  1. A0
  2. B1
  3. C
  4. D
我已思考，展开答案与解析
正确答案：D
  1. 积分是形状 n、速率 1 的 Gamma 变量 在其均值 n 以下的概率。可写 为 n 个独立 Exp(1) 的和。
  2. 由中心极限定理， 依分布趋于标准正态，所以该概率趋于 。
易错提醒这里区间端点随 n 变化，应先识别随机和及其标准化。
