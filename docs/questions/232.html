Bernoulli Fisher 信息

n个独立Bernoulli(p)观测，0<p<1。关于p的Fisher信息为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：A
  1. 单观测得分为(X−p)/[p(1−p)]，其方差为1/[p(1−p)]；独立样本的信息相加。
易错提醒先明确分布参数、独立性和统计量的定义，再进行计算。
