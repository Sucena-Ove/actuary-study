#151概率基本性质中等

事件分解

A与B独立，B与C独立，A与C互斥。P(A)=1/2，P(B)=1/4，P(C)=1/8。P(A∪B∪C)为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：D
  1. 三重交集为空，P(AB)=1/8，P(BC)=1/32。容斥得1/2+1/4+1/8−1/8−1/32=23/32。
易错提醒先明确分布参数、独立性和统计量的定义，再进行计算。
