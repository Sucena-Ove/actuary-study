圆周几何概率

圆周上独立均匀取3点，三点能落在某个半圆内的概率为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：B
  1. 指定一点作为覆盖半圆的起点，另两点落在顺时针半圆的概率为1/4。连续分布下边界事件概率0，3种起点事件几乎不交，总概率3/4。
易错提醒先明确分布参数、独立性和统计量的定义，再进行计算。
