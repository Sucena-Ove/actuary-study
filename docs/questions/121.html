#121概率基本性质中等

中断比赛的公平分配

两人每局独立且各以1/2概率获胜。中断时甲还需2胜、乙还需3胜。按最终胜率分配奖金，甲的份额为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：B
  1. 甲获最后一胜前，乙可已赢0、1、2局。概率为1/4+2/8+3/16=11/16。
易错提醒先明确分布参数、独立性和统计量的定义，再进行计算。
