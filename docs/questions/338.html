#338假设检验中等

固定阈值检验的相合性

独立样本来自 Pois，检验 对 ，拒绝域为 。当 n 趋于无穷时，两类错误概率分别趋于？
  1. A1 和 1
  2. B0 和 0
  3. C0 和 1
  4. D1 和 0
我已思考，展开答案与解析
正确答案：B
  1. 原假设下 依概率趋于 2，故超过 2.8 的概率趋于 0。
  2. 备择下 依概率趋于 3，故小于 2.8 的概率趋于 0。
易错提醒这是固定分隔阈值的检验；不能把显著性水平误认为一直固定在某个非零数。
