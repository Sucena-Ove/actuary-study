离散与连续的卷积

X在{1,…,n}上离散均匀，Y与X独立、密度为f。X+Y的密度为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：B
  1. 按X=k条件化，每个条件密度是平移后的f(t−k)，再按1/n加权求和。
易错提醒先明确分布参数、独立性和统计量的定义，再进行计算。
