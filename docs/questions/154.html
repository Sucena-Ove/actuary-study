#154概率基本性质中等

条件试验

先抛公平硬币：正面时抛1枚公平六面骰，反面时抛2枚独立公平六面骰。记录骰子点数和Y。P(Y=4)为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：C
  1. 单骰为4概率1/6，双骰和为4概率3/36。加权为(1/2)(1/6)+(1/2)(3/36)=1/8。
