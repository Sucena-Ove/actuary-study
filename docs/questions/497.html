#497随机向量中等

给定总次数后的子区间计数

是任意正速率的齐次泊松过程，给定N(4)=6。则 为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：A
  1. 给定总区间(0,4]内共有6次，每次事件落在前1个时间单位的条件概率为1/4。
  2. 子区间计数条件分布为Bin(6,1/4)，代入恰好2次公式。
易错提醒给定总数后不是原来的无条件泊松分布，且条件结果不依赖未知速率。
