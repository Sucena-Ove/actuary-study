#463概率基本性质基础

超几何：至少一好一坏

袋中5个好球、3个坏球，一次不放回抽2个。抽到至少一个好球且至少一个坏球的概率为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：C
  1. 抽2个时“至少一好一坏”就是恰好一好一坏。
  2. 有利组合数 ，总数 。
易错提醒若抽取多个球，事件“至少一个好”与“好坏都有”不同。
