串并联系统

某系统由两条并联支路组成，每条支路各含两个串联部件。四个部件相互独立，每个部件正常工作的概率均为 0.90。系统只要至少一条支路正常就能工作，其正常工作的概率为多少？
  1. A0.8100
  2. B0.9801
  3. C0.9639
  4. D0.6561
我已思考，展开答案与解析
正确答案：C
  1. 每条串联支路正常的概率为 ，失效概率为 。
  2. 两条支路使用不同且相互独立的部件，因此系统失效概率为 ，正常概率为 。
易错提醒串联要求全部正常，并联要求至少一条正常。
