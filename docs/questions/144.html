#144期望与预测中等

空盒指标法

n个球独立等概率投入n个盒子。空盒数的期望为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：A
  1. 每个盒子为空的概率为(1−1/n)ⁿ，将n个空盒指示量的期望相加。
易错提醒先明确分布参数、独立性和统计量的定义，再进行计算。
