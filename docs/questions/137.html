联合密度为 ，0<y<x<1。0<y<1时， 为？
  1. A
  2. B
  3. C
  4. D
我已思考，展开答案与解析
正确答案：B
  1. 固定y时x在(y,1)，条件密度 。令x=y+(1−y)u，则u均值1/3，故条件均值为y+(1−y)/3。
