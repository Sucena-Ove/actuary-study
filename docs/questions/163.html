#163概率基本性质中等

对称信道与先验

输入AAA、BBB、CCC的先验概率为0.4、0.3、0.3。各字符独立传输，正确概率α，错成任一其他字符概率(1−α)/2，0<α<1。收到ABC后，输入AAA的概率为？
  1. A1/3
  2. B0.6
  3. Cα
  4. D0.4
我已思考，展开答案与解析
正确答案：D
  1. 任一原始三连字符生成ABC的似然都为α[(1−α)/2]²，三者相同，因此后验等于先验。
易错提醒先明确分布参数、独立性和统计量的定义，再进行计算。
